# ARS Green Steel Navigation Strategy

## Purpose

This document defines the navigation strategy for the ARS Green Steel website.

The navigation must support two outcomes:

- Generate qualified enquiries from home owners, engineers, contractors, dealers, distributors, and procurement teams.
- Build trust through products, proof, certifications, manufacturing strength, and clear buying assistance.

The site should not behave like a passive company brochure. It should guide visitors from discovery to decision: understand ARS, verify proof, choose the right product, check price or calculate requirement, find a dealer, and submit an enquiry.

## Strategic Navigation Principles

- Lead with buyer intent, not company hierarchy.
- Keep enquiry paths visible on every major page.
- Use simple industrial labels that users understand quickly.
- Group technical proof close to product and enquiry paths.
- Make tools easy to find: steel price, calculator, dealer locator, and quote.
- Use `#004B9B` for primary CTAs, active states, links, and navigation highlights.
- Use `#F76369` only for small accent moments, not as the primary navigation or CTA color.
- Avoid deep page nesting on mobile.
- No important page should end without a next action.

## 3. Internal Linking

### Homepage Linking

The homepage should link to:

- Products
- Steel Price Today
- TMT Calculator
- Dealer Locator
- Request Quote
- Quality Certifications
- Manufacturing
- Green Steel
- Industries / Applications
- Contact

Homepage linking priority:

1. Hero CTAs should lead to Steel Price or Products.
2. Buying Assistant should lead to Steel Price, Calculator, Dealer Locator, and Request Quote.
3. Product Range should lead to product detail pages.
4. Audience Paths should lead to audience or relevant tool paths.
5. Quality and Manufacturing should lead to Certifications and Technical Support.
6. Final Contact CTA should lead to Request Quote and Call Sales.

### Product Page Linking

Every product page should link to:

- Request Quote
- TMT Calculator
- Dealer Locator
- Technical Specifications
- Quality Certifications
- Relevant Industries
- Manufacturing Process
- Download Brochure

Product pages should never be dead ends. After users understand a grade, they should be able to act immediately.

### Services Page Linking

Services should connect the buying tools into one flow:

- Steel Price Today links to Calculator, Dealer Locator, and Request Quote.
- TMT Calculator links to Product Details, Dealer Locator, and Request Quote.
- Dealer Locator links to Products, Steel Price, and Contact Sales.
- Request Quote links to Calculator if users are unsure about quantity.

### Industries Page Linking

Each industry/application page should link to:

- Recommended products
- Calculator
- Dealer Locator
- Certifications
- Request Quote

The purpose is to convert project context into a specific product and enquiry path.

### Certifications Page Linking

Certification pages should link to:

- Products
- Manufacturing
- Technical Specifications
- Downloads
- Request Technical Support
- Request Quote

Trust content should always support a commercial next step.

### Contact And Enquiry Linking

Contact should link to:

- Request Quote

Enquiry should link back to:

- Products

## 6. Mobile Navigation

Mobile navigation should be built around quick action first, then browsing.

Recommended mobile structure:

1. Logo and Get Quote CTA in header
2. Menu button
3. Quick action panel:
   - Check Steel Price
   - Calculate Requirement
   - Find Dealer
   - Request Quote
4. Accordion navigation:
   - Products
   - Services
   - Industries
   - Projects
   - Certifications
   - About
   - Contact
5. Footer-style support links:
   - Call Sales
   - WhatsApp
   - Download Brochure

Mobile rules:

- Keep tap targets at least 44px.
- Avoid more than two navigation levels.
- Use clear labels, not icon-only links.
- Make Get Quote visible without scrolling inside the menu.
- Use blue for active states and primary actions.
- Keep red as a small accent only.
- Make menu open/close behavior accessible by keyboard and screen readers.

## Recommended Build Sequence

1. Extract Header and Footer as reusable components.
2. Create the desktop navigation model.
3. Add mobile navigation with quick actions.
4. Add mega menu panels for Products, Services, Industries, Certifications, and About.
5. Connect existing homepage anchors to future routes.
6. Add active states, focus states, and accessible menu behavior.
7. Test desktop, tablet, and mobile navigation.

## Final Direction

The ARS Green Steel navigation should make the site feel like a practical industrial buying system.

The core flow should remain clear everywhere:

Proof builds trust. Products explain the offer. Services help users act. Industries make it relevant. Enquiry turns interest into sales.
